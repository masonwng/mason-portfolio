# Favicon asset

Created with the built-in image-generation tool from the user's supplied portrait reference. The photograph is not stored in this repository.

Final prompt:

> Create a cartoon favicon of this person's head only on transparent background. Match his likeness closely: naturally long narrow face, long jaw and chin, normal small almond eyes, neutral mouth, messy black hair. Do not shorten or round his face. Clean flat cartoon shapes, bold outlines, not anime. Front view, head only, no hoodie or background, no text. Centered in a square, small margins.

The generated head is resized into `public/avatar-mason.png`, `app/icon.png`, `app/favicon.ico`, and `app/apple-icon.png`. Keep transparency when replacing it. The SVG pig favicon was removed so it does not override the new face icon.
