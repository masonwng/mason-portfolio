      how to play & data sources

      Champion hints: identify one selected item from verified champion relationships. Complete the build: fill the marked slot in a published core sequence. Some other slots stay hidden on higher difficulties. A miss reveals another clue.

      Easy: eight attempts, three hints, 1× score. Normal: five attempts, two hints, 1.5×. Hard: three attempts, one hint, 2×. Start at 100 points; misses cost 15 and requested hints cost 20, then apply the multiplier. A lost round scores zero. All scores are local puzzle scores.

      This is a small editorial question bank, manually checked against four public U.GG pages. It is not a live U.GG API or a complete champion database. We do not redistribute U.GG statistics. Patch, review date, and source links are shown with every round. Item and champion metadata and artwork come from Riot Data Dragon.

      Core builds are examples for the stated patch and role. Matchups and game state can change good choices. No situational questions are generated without supported data. If the snapshot is older than the current patch, it remains playable as a clearly labeled historical puzzle.
